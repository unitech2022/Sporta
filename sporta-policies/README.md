# موقع سياسات سبورتا

مشروع مستقل يُنتج صفحات **ثابتة** للوثائق القانونية (سياسة الخصوصية، الشروط
والأحكام، سياسة الاسترجاع) بالعربية والإنجليزية، لرفعها على دومين منفصل.

الرابط الذي تعطيه لمتجري آبل وجوجل بعد الرفع:
`https://<دومينك>/privacy-ar.html`

## من أين يأتي النص

من الـ API مباشرة عبر `GET /api/settings/public/{key}` — وهو نفس المصدر الذي
يقرأ منه التطبيق. يعني: **ما يحرّره الأدمن في لوحة التحكم هو ما يُنشر هنا**، ولا
توجد نسخة ثانية من النص تُنسى فتتناقض مع التطبيق.

لكن الناتج ملفات ثابتة، فهي مجمّدة على لحظة البناء: **أعد البناء وارفع بعد كل
تعديل على السياسات**.

## الاستخدام

```bash
cd sporta-policies
npm run build      # يبني dist/ من الإنتاج
npm run preview    # يبني ثم يفتح معاينة على http://localhost:4173
```

بلا أي تبعيات — لا `npm install` ولا `node_modules`. يكفي Node 18 فأحدث.

للبناء من باك إند محلي بدل الإنتاج:

```bash
API_BASE=http://localhost:7050 npm run build
```

## قبل أول بناء

عدّل `site.config.mjs`:

| الحقل | لماذا يهم |
|---|---|
| `siteUrl` | دومينك. يدخل في `canonical` و`hreflang` و`sitemap.xml` — والقيمة الخاطئة تربك محركات البحث |
| `contactEmail` | يظهر في تذييل كل صفحة (اتركه فارغاً لإخفائه) |
| `documents` | الوثائق المنشورة؛ احذف سطراً لتتوقف صفحته عن الصدور |
| `home` | الوثيقة واللغة اللتان يفتح عليهما جذر الدومين |

## الرفع

ارفع **محتويات** `dist/` إلى جذر الدومين (لوحة الاستضافة، أو nginx، أو أي مستضيف
ملفات ثابتة). لا تحتاج Node على الخادم — كلها HTML جاهز.

```
dist/
├── index.html          ← جذر الدومين، يحوّل للوثيقة الافتراضية
├── privacy-ar.html     privacy-en.html
├── terms-ar.html       terms-en.html
├── refund-ar.html      refund-en.html
├── sitemap.xml
└── robots.txt
```

كل صفحة مكتفية بذاتها: التنسيق مضمّن بداخلها، بلا JavaScript ولا خطوط أو صور
خارجية، والروابط بينها نسبية — فتعمل في جذر الدومين أو داخل مجلد فرعي أو حتى
مفتوحة من القرص.

### روابط أنظف (اختياري)

لو أردت `‎/privacy/ar` بدل `‎/privacy-ar.html`، أضف في nginx:

```nginx
rewrite ^/(privacy|terms|refund)/(ar|en)/?$ /$1-$2.html last;
```

## البديل: لا ترفع شيئاً

الـ API نفسه يقدّم الصفحات ذاتها على `/privacy/ar` و`/privacy/en`
(`SportaApis/Controllers/PolicyPagesController.cs`). إن كنت تنشر الباك إند على
أي حال فاستخدم `https://apis.sportaapp.net/privacy/ar` — يقرأ النص الحيّ من قاعدة
البيانات فيتحدّث فور تعديل الأدمن، بلا إعادة بناء ولا رفع. هذا المشروع لمن يريد
دوماً منفصلاً عن دومين الـ API.

## ملاحظة أمنية

نص السياسات يحرّره الأدمن، ويُهرَّب من HTML قبل الطباعة في `src/render.mjs` — فلا
يتحول حقل التعديل في اللوحة إلى ثغرة XSS على دومينك. لا تُزل التهريب عند التعديل.
